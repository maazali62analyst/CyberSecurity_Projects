## How to use a project
Each project lives in its own self-contained folder with its own README. To use just one:
1. Open the project folder in this repo.
2. Download that folder (for example with download-directory.github.io) or clone the repo and copy the folder.
3. Follow the "Run locally" steps in that project's README.
